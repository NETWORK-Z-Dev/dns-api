Free Subdomains with API!

Getting started with self-hosting is easier than ever!

  • Create an account
  • Generate an api token
  • Paste the token in your app
  • Done!

The application will take care of the rest!
Alternatively you can manually edit your DNS entries.

How come?

Our goal is to improve the web and make self-hosting as easy and straight forward as possible.

This includes making the SSL/TLS setup easier by providing free subdomains in combination with caddy!
